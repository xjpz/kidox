## 关于 KidoX

本仓库基于 [defcc/kidox.app](https://github.com/defcc/kidox.app)，由 [xjpz/kidox](https://github.com/xjpz/kidox) 维护。在上游基础上加入中文拼音搜索、可配置负一屏、固定应用和小屏启动模式，主应用 Bundle Identifier 为 `cc.xjpz.KidoX`。

KidoX 提供熟悉的启动台网格，让你通过鼠标、键盘或触控板浏览、整理和启动 Mac 应用。它使用 SwiftUI 构建，是独立的 macOS 应用，不需要修改系统启动台。

## 功能

基础功能：

- 启动台风格网格，支持分页、文件夹、拖动整理和键盘导航。
- 原地搜索，支持中文名称、英文名称、全拼和拼音首字母。
- 默认排序下可开启负一屏：默认 **6 × 4，最多 24 个应用**，可选 **7 × 5，最多 35 个应用**，保留普通页面的原有布局。
- 固定应用排在负一屏前部，全屏与小屏共用固定顺序。
- 小屏启动模式，使用星形／四宫格图标直接切换常用与全部，支持搜索、文件夹和纵向滚动。
- 双指横滑切换，带方向一致的滑入／滑出动画，适配系统“减少动态效果”。
- macOS 26 小屏模式使用原生 Liquid Glass，较早系统使用兼容视觉效果材质。
- 支持 F4／启动台按键、自定义快捷键、触发角、菜单栏和 Dock 入口。
- 可选全局四指手势：捏合显示，展开隐藏。
- 自动扫描标准应用目录。
- 壁纸、玻璃和纯色背景模式，以及多语言界面。

Pro 功能：

- 最近使用、最常使用、最近添加、名称等排序方式。
- 隐藏应用。
- 内置卸载工具，支持关联数据清理和系统应用保护检查。
- 自定义图片背景。
- 备份与恢复布局、隐藏应用、启动统计、排序、快捷键、外观、Dock 图标、自定义背景及负一屏偏好。

全局四指手势默认关闭，使用运行时加载的 macOS 私有多点触控框架，因此上游官方版本通过 Mac App Store 之外的渠道分发。

## 环境要求

- 运行应用：macOS 15 或更高版本。
- 编译当前源码：Xcode 26 或更高版本，包含 macOS 26 SDK。
- Xcode 命令行工具。

## 本地开发

在 Xcode 中打开 `KidoXApp.xcodeproj`，选择 `KidoX` Scheme 运行。使用自己的签名团队，并确保主应用与特权辅助程序的签名校验要求一致。

也可以从命令行构建：

```sh
xcodebuild -project KidoXApp.xcodeproj -scheme KidoX -configuration Debug build
```

项目依赖通过 Swift Package Manager 由 Xcode 解析。

## 使用说明

### 负一屏与固定应用

在 **设置 → 通用 → 负一屏** 中配置“开启”和“布局”。负一屏仅在默认排序且没有搜索时显示，位于普通第一页左侧。

- 默认 **6 × 4／24 个**，可选 **7 × 5／35 个**；网格紧凑，末行左对齐，没有额外标题或副标题。
- 布局立即生效并自动保存；关闭负一屏会保留布局、固定和排除记录。
- 推荐根据通过 KidoX 启动应用的次数生成，包括文件夹内应用；不统计通过 Dock、Finder 等其他入口的启动行为。
- 隐藏、不可用或已排除的应用不参与推荐。
- 右键应用可选择“固定到负一屏”或“取消固定”。固定项优先显示，与推荐项合计占用 24／35 个位置；未使用过的应用也可以固定，不改变它在普通页或文件夹中的位置。
- 固定项可在负一屏网格中拖动排序。设置中的固定应用列表只提供取消固定，应用图标上不显示固定角标。
- 缩小布局会保留超出容量的固定记录，切回更大布局后可再次显示。取消固定后，该应用仍可能出现在常用推荐中。
- 未固定的推荐应用可右键选择“不再推荐此应用”，也可以在设置中恢复。推荐顺序在本次打开期间保持稳定，切换布局时按新容量刷新。
- 方向键按当前列数导航；开关、布局、固定和排除列表都包含在设置备份中。

同一次运行期间，全屏模式记住上次浏览页，包括负一屏。从搜索返回时恢复搜索前的页面；完全退出并重启后从普通第一页开始。详见[负一屏说明](docs/recommendations.md)。

### 小屏模式

在 **设置 → 通用 → 启动方式 → 小屏模式** 中启用。全屏仍为默认启动方式；全屏齿轮菜单也提供“小屏模式”入口，小屏工具栏可返回全屏。

- 面板约 **920 × 640 pt**，按当前显示器可用区域适配，可拖动工具栏调整位置。
- 星形／四宫格直接切换常用与全部，不使用下拉导航。搜索框最大宽度 360 pt，右侧齿轮打开设置菜单。
- 双指向右滑可从全部返回负一屏，向左滑从负一屏进入全部，方向遵循系统滚动设置，两端不循环。
- 横滑及点击导航图标使用约 **0.28 秒**的滑入／滑出与淡入淡出，顶部工具栏保持固定。开启系统“减少动态效果”时改用短暂淡入淡出。
- 页面在手势结束后切换，目前不随手指连续拖动。纵向手势继续滚动列表；轻微或意图不明确的斜滑、惯性尾段不会反复切页。搜索、文件夹内和固定拖动期间保持各自交互。
- macOS 26 使用原生 Liquid Glass，背景随系统外观和桌面内容变化；较早系统使用兼容视觉效果材质。
- 全部应用按原有页面和文件夹顺序纵向浏览；常用页使用所选 6 × 4 或 7 × 5 布局。
- 搜索覆盖所有可见应用，包括文件夹内容；Esc 依次清空搜索、退出文件夹、关闭面板。
- 成功启动应用后关闭面板；全屏与小屏分别记住本次运行中的浏览位置。
- 固定列表和启动方式参与设置备份，不新增屏幕录制权限。

普通应用的拖动整理仍在全屏模式进行。详见[设计方案](docs/pinned-apps-compact-launcher-design.md)与[实施验证](docs/pinned-apps-compact-launcher-implementation.md)。

### 搜索

支持中文、英文、全拼和拼音首字母，例如：

| 输入 | 示例结果 |
| --- | --- |
| `x`、`xtsz` | 系统设置 |
| `wx`、`weixin` | 微信 |

默认排序下，完整首字母匹配优先于更长的前缀匹配。应用别名按语言区分，减少无关外语名称对单字母搜索的干扰。索引在后台构建，并随名称变化更新。

### 应用标识与旧备份

主应用使用 `cc.xjpz.KidoX`，IPC、Dock 插件和辅助程序使用相同前缀。由旧标识升级时会使用新的偏好域，可在设置中导入之前导出的备份恢复偏好；macOS 可能要求重新授予原有系统权限。

布局数据库仍位于 `~/Library/Application Support/KidoX/pages.json`。备份格式、`.kidoxbackup` 扩展名和原有备份文件类型标识保持兼容。更改应用标识不会删除旧偏好或布局数据。详见[标识调整说明](docs/bundle-identifier-change.md)。

## 测试

运行搜索、推荐、固定应用、页面映射、手势及兼容性测试：

```sh
xcodebuild -project KidoXApp.xcodeproj -scheme KidoXRecommendations -destination 'platform=macOS' test
```

该 Scheme 不启动 KidoX，也不加载用户应用数据库；相关测试也注册在主 `KidoX` Scheme 中。
