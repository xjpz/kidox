# 负一屏

在「设置 → 通用 → 负一屏」开启或关闭。仅在默认排序、非搜索状态下显示；关闭不会改变原有应用页或使用记录。

## 布局与推荐

- 默认 6 × 4，最多 24 个应用；可选 7 × 5，最多 35 个应用。
- 网格整体水平居中，末行左对齐；横向间距上限为卡片宽度 + 20 pt，行间距为卡片高度 + 32 pt。
- 按从 KidoX 打开的次数、最近打开时间及稳定标识排序，包括文件夹内应用；过滤隐藏、不可用和不再推荐的应用，不补占位图标。
- 每次打开时生成推荐快照，避免使用过程中重排。主动切换布局会按新容量重新生成快照；排除立即生效，恢复的应用在下次打开时参与推荐。
- 右键应用可固定到负一屏，固定项在前，剩余位置按使用频次补足，总量仍为 24/35；应用无固定角标。固定可在负一屏拖动排序，设置列表只提供取消固定，不改变普通页或文件夹位置。
- 未固定的推荐项可右键选择「不再推荐此应用」，设置中可管理和恢复。取消固定后仍可能出现在常用部分。
- 未使用过的应用也可固定；隐藏、不可用项保留固定记录但不显示。切换到较小布局不会删除超额固定项。
- 上下方向键按所选布局跨 6 或 7 个位置，推荐页内导航不会跨入普通页。

## 页面与偏好

负一屏使用独立的展示页标识，不写入真实应用页。拖拽、搜索返回、普通页增删均通过真实页标识定位，避免负一屏造成索引偏移。

同一次运行期间记住上次浏览页，包括负一屏；搜索退出或启动应用后恢复搜索来源。完全退出并重启后从普通第一页开始。

开关、布局、有序固定列表和排除列表自动保存，并随设置备份导入、导出。布局使用 `KidoX.recommendations.layout`，值为 `6x4` 或 `7x5`；旧配置、旧备份及未知布局值回退至 6×4。关闭再开启会保留布局选择。

## 验证

`KidoXRecommendations` scheme 覆盖推荐排序与容量切换、去重和过滤、页面恢复、键盘导航、紧凑布局、偏好持久化及备份兼容，并包含已有搜索测试。

```sh
xcodebuild -project KidoXApp.xcodeproj -scheme KidoXRecommendations \
  -destination 'platform=macOS' test
```

设置界面已验证默认 6×4、切换 7×5、关闭时选择器置灰、重新开启保留选择，以及恢复默认布局。
