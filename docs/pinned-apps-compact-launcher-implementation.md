# 固定应用与小窗启动模式实施记录

日期：2026-09-11。

## 功能与入口

- 「设置 → 通用 → 启动方式」选择全屏/小窗；原配置缺省为全屏。全屏齿轮菜单提供「小屏模式」，小屏工具栏可返回全屏，两种模式共用应用、搜索和启动计数。
- 小窗约 920×640 pt，按当前屏幕可用区域收缩；工具栏可拖动，同一次运行按屏幕记住位置。全部列表纵向滚动，不重新划分普通页或移动文件夹内容。
- 常用/全部采用 12 pt 星形、四宫格直接切换，选中背景 26×26 pt，点击区域 30×30 pt。没有下拉式导航，应用图标没有固定角标。搜索框最大宽度为 360 pt、高 36 pt；右侧全屏图标 12 pt，设置采用齿轮图标。
- 小窗支持文件夹、全局搜索、方向键、回车启动及分层 Esc。菜单保留设置入口，普通应用重排通过「在全屏整理应用」完成。
- 普通页、搜索、文件夹及小窗可右键固定/取消固定；负一屏中可拖动固定项排序。设置固定应用列表只保留取消固定，不提供添加或排序控件；负一屏开关、布局文案简化为「开启」「布局」。
- 有效固定项在前，常用快照补足剩余位置，合计最多 24/35。隐藏或未安装项不显示；缩小布局不删除超额固定记录。固定与排除冲突由固定动作统一消解。
- 固定顺序、默认启动模式加入原有设置备份；继续兼容 schema 1 的旧备份，不修改应用数据结构。

## 实现边界

`RecommendationPreferences` 保存固定列表，推荐引擎把无使用次数的固定项与常用排名分开解析。`CompactLauncherPanelController` 负责小窗，仍由现有面板控制器协调显示，共用一个 `KidoXStore`。小窗滚动以可见行的应用身份恢复，SwiftUI 与原生滚动容器之间的连接局限在一个辅助视图。

成功启动后沿用同一个启动回调记数并关闭小窗；失败保留界面并显示错误。未新增屏幕采集或其他权限，也未加入远程推荐服务。

## 双指切换与背景材质

- 在根列表中，向右滑从全部回到负一屏，向左滑从负一屏进入全部；两端不循环。仍遵循系统滚动方向。
- 同一手势锁定横向/纵向意图，横向累计达到 48 pt 并结束才切换；惯性不二次触发，纵向列表不被接管。搜索、输入法组合、文件夹内和固定拖动期间保持原交互。
- 监听只处理当前小屏窗口的滚轮事件，窗口释放时移除；复用原有浏览锚点和导航，不新增全局手势权限。
- macOS 26 使用 `NSGlassEffectView` 的 regular 材质，直接包裹窗口内容，移除 SwiftUI 外层的旧弹出材质、裁切和描边。此前与系统面板有区别的背景来自旧材质路径；原生玻璃随系统外观、桌面内容和辅助功能设置变化，不声称与系统应用逐像素一致。
- 旧系统保留 AppKit 视觉效果材质。新增手势回归覆盖左右、纵向锁定、斜滑、阈值、取消、惯性及无 phase 滚动事件。

## 小屏切页动画
